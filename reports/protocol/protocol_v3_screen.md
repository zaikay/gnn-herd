# Protocol v3 screen — 31 October 2026

Approved researcher instruction: screen three architectures after the accepted diagnostics. **Gate C remains open.** This note adds an exploratory screen; frozen v1/v1.1/v2 files and completed campaigns remain unchanged. Proposed tag: `protocol-v3-screen`. No final-test access.

- **A:** independent self and neighbour projections inside the GRU gates/candidate. Neighbours are an observed-neighbour-only arithmetic mean, with no self edge. Empty sets contribute zero.
- **B:** local GRU, direct local forecast head and a late linear correction from neighbour-mean hidden state minus own hidden state. The correction is zero for isolates and initialised at zero. Softplus gives positive rates.
- **C:** the B network produces a log correction to the frozen v1.1 selected own-lag boosting base: `forecast = base * exp(correction)`. Local and neighbour correction heads start at zero. Zero correction returns the positive stored base exactly. No extra base feature/channel is added. The base is fixed, with no joint boosting optimisation. For every candidate, no graph uses the same full parameterisation with its neighbour branch set to zero.

**Screen:** A, then B, then C; within each, August 2019 and August 2020 anchors, real then no graph. Seed 11, width 64, Adam learning rate 0.003, decay 0.0001, 65 epochs, six original channels, lookback 24, batch two origins, existing Poisson loss and target/unknown-node masks. Twelve GPU fits on the same Windows RTX 4070 laptop (8 GB VRAM, 32 GB RAM). Retain completed checkpoints and five-epoch recovery, deterministic seed/epoch ordering, fit wall time and peak allocated/reserved VRAM. Overflow/nonfinite rates stop the run; no silent clipping, objective or epoch change.

**C base dates:** freeze the v1.1 selected own-lag configuration (learning rate 0.03, 15 leaves, L2=1, 300 iterations, no early stopping), seed 11. A/B keep the original training calendar. This difference is a declared limitation of cross-candidate interpretation. No target/source/record is deleted from the panel.
